# Todo List App

Une application de gestion de tâches développée avec React et Vite.

## Fonctionnalités

- Authentification (inscription / connexion / déconnexion)
- Ajouter, supprimer et compléter des tâches
- Filtrer les tâches par statut (Toutes / Actives / Complétées)
- Compteur de tâches restantes
- Design dark mode

## Technologies utilisées

- React
- React Router
- Vite
- CSS

## Installation
```bash
git clone https://github.com/cidevalgames/todo-app.git
cd todo-app
npm install
npm run dev
```
